| 단계 | 범위 | 내용 |
| :--- | :--- | :--- |
| 1차 | 간편로그인 | 회원가입(ID/간편로그인), 로그인(ID/간편로그인), 계정 통합 |

| 3차 | 주석 편집 | 실시간 동기화 |
| 4차 | 공유 설정 | 공유 대상과 권한 설정 |
| 5차 | 협업 작업 구성 | 동시 수정 |
| 6차 | 오프라인 작업 | 작업 중 오프라인, 오프라인 업로드, 온라인 전환 |
| 7차 | PDF OCR 처리 | OCR 처리 기능 고도화 |
