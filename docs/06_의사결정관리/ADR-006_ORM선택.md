# ADR-006. ORM 선택

## 상태

승인됨

## 배경

MVP1 인증은 사용자, 로컬 로그인 정보, 검증 이메일, OAuth 식별자, 계정 통합 요청, 감사 로그를 다룬다. 데이터관리 기준의 UUID, 공통코드, 공통 메타 컬럼, 유니크 제약을 실제 DB 스키마에 명확히 반영해야 한다.

## 결정

DB는 PostgreSQL, ORM은 Drizzle ORM을 채택한다.

1. PostgreSQL을 기본 관계형 DB로 사용한다.
2. Drizzle ORM으로 테이블, 제약, 마이그레이션을 관리한다.
3. `auth_identity(provider_cd, provider_user_id)`는 유니크 제약으로 강제한다.
4. `local_credential.login_id`와 `verified_email.email`은 유니크 제약 후보로 관리한다.
5. 복잡한 계정 통합 변경은 트랜잭션 안에서 처리한다.

## 결과

### 긍정적 영향

- SQL 제약과 타입 안정성을 함께 관리할 수 있다.
- 데이터관리 설계기준의 물리 규칙을 스키마 코드에 명시하기 쉽다.
- 마이그레이션 산출물을 리뷰하기 쉽다.

### 부정적 영향

- Prisma보다 고수준 CRUD 생산성은 낮을 수 있다.
- 실제 DB 연결과 마이그레이션 도구 설정이 필요하다.

## 후속 작업

- MVP1 인증 테이블 스키마를 Drizzle 기준으로 작성한다.
- 테스트 DB와 마이그레이션 실행 명령을 개발 명령어 문서에 반영한다.
