# 11. 로그 및 백로그 관리

## 목적

PDFowers 작업 과정에서 발생하는 부가 작업, 기술 부채, 후속 아이디어, 발견 항목(Discovery), 회고 및 운영 로그를 구조화하여 관리한다.

| 백로그 대장 | [백로그_대장.md](./백로그_대장.md) | 작업 중 발견된 부가 작업, 기술 부채, 개선 아이디어, 후속 처리 항목 등록 및 상태 추적 |

## 백로그 등록 및 운영 규칙

1. **등록 시점**: 세션 또는 태스크 진행 중 즉시 해결하기 어렵거나 후속 작업으로 분리해야 하는 항목이 발생했을 때 등록한다.
2. **세션정리 연계**: `#세션정리` 실행 시 이번 세션에서 새로 발생한 항목을 백로그 대장에 갱신하고, 해결된 항목의 상태를 반영한다.
3. **항목 식별자 규칙**: `BL-YYYYMMDD-순번` 형식을 사용한다 (예: `BL-20260913-001`).
4. **상태값**:
   - `OPEN`: 신규 등록되어 처리가 필요한 상태
   - `IN_PROGRESS`: 현재 세션/태스크에서 진행 중인 상태
   - `RESOLVED`: 해결/구현이 완료된 상태
   - `DEFERRED`: 후속 마일스톤 또는 장기 검토로 보류된 상태
   - `CANCELLED`: 요구사항 변경 등으로 취소된 상태
