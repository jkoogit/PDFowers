# 05. MVP1 테스트 정의서

## 1. 범위

본 문서는 MVP1 인증/검수 기능의 자동화 테스트와 수동/운영 검증 항목을 정의한다. 기준은 `docs/05_테스트관리/04_MVP1_AUTH_커버리지.md`, `test/unit`, `test/integration`, 최근 세션 리뷰 문서다.

## 2. 테스트 환경

| 환경 | 용도 | 명령/접근 |
| :--- | :--- | :--- |
| 로컬 Node/Vitest | 단위 테스트, 빌드 검증 | `npm run typecheck`, `npm run test:unit`, `npm run build` |
| PostgreSQL 통합 테스트 | 실제 DB schema/repository 검증 | `npm run test:integration` with `DATABASE_URL` |
| MVP1 검수 서버 | 브라우저 기반 검수 | `npm run review:mvp1` |
| dev NAS | 배포 smoke 및 Kakao 이동 검증 | `https://jkok2.myqnapcloud.com:4443` |

## 3. 자동화 테스트 명령

| 명령 | 목적 | 현재 기준 |
| :--- | :--- | :--- |
| `npm run typecheck` | TypeScript 타입 검증 | 필수 |
| `npm run test:unit` | 단위 테스트 전체 | 필수 |
| `npm run test:integration` | PostgreSQL 통합 테스트 | `DATABASE_URL` 설정 시 수행 |
| `npm run build` | dist 빌드 | 필수 |
| `npm run review:kakao-smoke -- --base-url <URL>` | 배포 Kakao smoke | dev NAS 인증서 체인 이슈로 후속 보완 필요 |

## 9. 검증 게이트

작업 PR 전 최소 검증:

```powershell
git diff --check
npm run typecheck
npm run test:unit
npm run build
```

DB 또는 배포 변경 포함 시 추가 검증:

```powershell
npm run test:integration
npm run review:kakao-smoke -- --base-url <환경 URL>
```

단, 현재 dev NAS는 Node 인증서 체인 문제로 `review:kakao-smoke`가 실패할 수 있으므로, 원인 해결 전까지는 PowerShell 또는 브라우저 기반 `/`, `/auth/kakao/config-status`, `/auth/kakao/start` 확인 결과를 병행 기록한다.
