# 02. MVP1 시퀀스 다이어그램

## 1. ID/PW 회원가입 및 로그인

```mermaid
sequenceDiagram
    participant R as 검수화면/Client
    participant S as MVP1 Review Server
    participant D as Auth Domain
    participant P as Persistence

    R->>S: POST /auth/signup/local
    S->>D: createLocalUser(loginId,email,password,displayName)
    D-->>S: AuthUser(passwordHash, verifiedEmails)
    S->>P: persist(state)
    P-->>S: persisted state
    S-->>R: 200 { ok, user, state } + session cookie

    R->>S: POST /auth/login/local
    S->>D: verifyLocalLogin(user,password,emailVerificationRequired)
    alt 성공
        D-->>S: ok, userUuid
        S->>P: persist(state)
        S-->>R: 200 { ok, user, state } + session cookie
    else 실패
        D-->>S: INVALID_CREDENTIALS 또는 EMAIL_VERIFICATION_REQUIRED
        S-->>R: 401 { error, state }
    end
```

## 2. Kakao 실제 OAuth 로그인

```mermaid
sequenceDiagram
    participant U as 사용자
    participant B as Browser
    participant S as MVP1 Review Server
    participant K as Kakao OAuth
    participant D as Auth Domain
    participant P as Persistence

    U->>B: 카카오 로그인 시작
    B->>S: GET /auth/kakao/start
    S->>S: config-status 및 redirect policy 확인
    S->>S: oauth state 생성, cookie 저장
    S-->>B: 302 Kakao authorize URL
    B->>K: authorize 요청
    K-->>B: callback(code,state)
    B->>S: GET /auth/kakao/callback?code&state
    S->>S: cookie state와 query state 검증
    S->>K: token exchange
    K-->>S: access token
    S->>K: profile 조회
    K-->>S: Kakao profile
    S->>D: findOAuthLogin 또는 createOAuthUser
    S->>P: persist(state)
    S-->>B: 303 /?kakao=success + session cookie
    B->>S: GET /
    S-->>B: 검수화면
```

## 3. Mock OAuth 가입/로그인

```mermaid
sequenceDiagram
    participant R as 검수화면
    participant S as MVP1 Review Server
    participant D as Auth Domain

    R->>S: POST /auth/oauth/:provider/callback
    S->>D: findOAuthLogin(provider, providerUserId)
    alt 기존 identity 있음
        D-->>S: ok, userUuid
        S-->>R: 200 기존 사용자 로그인
    else 기존 identity 없음 + 가입 payload 있음
        S->>D: createOAuthUser(loginId,email,password,provider,providerUserId)
        D-->>S: 신규 사용자
        S-->>R: 200 신규 OAuth 가입
    else 가입 payload 없음
        S-->>R: 404 OAUTH_SIGNUP_REQUIRED
    end
```

## 4. 로그인 수단 연결 및 계정 통합 요청

```mermaid
sequenceDiagram
    participant U as 로그인 사용자
    participant R as 검수화면/Client
    participant S as MVP1 Review Server
    participant D as Auth Domain
    participant N as Notification
    participant P as Persistence

    U->>R: provider 연결 요청
    R->>S: POST /auth/identities/:provider
    S->>S: session cookie로 currentUser 조회
    S->>D: linkOAuthIdentity(currentUser, allUsers, provider, providerUserId)
    alt 미사용 provider identity
        D-->>S: ok
        S->>P: persist(state)
        S-->>R: 200 { ok, user, state }
    else 현재 계정에 이미 연결
        D-->>S: AUTH_IDENTITY_ALREADY_LINKED
        S-->>R: 409 { error, state }
    else 다른 계정에 연결됨
        D-->>S: ACCOUNT_MERGE_REQUIRED + mergeRequest
        S->>N: createAccountMergeRequestedNotifications
        N-->>S: sample/SMTP notification events
        S->>P: persist(state)
        S-->>R: 409 { error, mergeRequest, state }
    end
```

## 5. 계정 통합 승인

```mermaid
sequenceDiagram
    participant R as 검수화면/Client
    participant S as MVP1 Review Server
    participant D as Auth Domain
    participant N as Notification
    participant P as Persistence

    R->>S: POST /auth/merge-requests/:id/approve
    S->>S: session 및 mergeRequest 조회
    S->>D: approveMergeRequest(requestUser,targetUser,mergeRequest)
    alt 승인 가능
        D->>D: target identity를 requestUser로 이전
        D->>D: targetUser.status = merged
        D->>D: audit log 기록
        D-->>S: ok
        S->>N: createAccountMergeApprovedNotifications
        S->>P: persist(state)
        S-->>R: 200 { ok, state }
    else 취소/만료/중복 승인
        D-->>S: MERGE_REQUEST_CANCELLED/EXPIRED/NOT_PENDING/DUPLICATE
        S-->>R: 409 { error, state }
    end
```


## 7. 예외 흐름

| 흐름 | 예외 | 처리 |
| :--- | :--- | :--- |
| Kakao callback | code 없음 | `/?kakao_error=KAKAO_OAUTH_CODE_REQUIRED`로 복귀 |
| Kakao callback | state mismatch | `/?kakao_error=KAKAO_OAUTH_STATE_MISMATCH`로 복귀 |
| Kakao callback | token/profile 실패 | `/?kakao_error=KAKAO_OAUTH_CALLBACK_FAILED`로 복귀 |
| 계정 연결 | 인증 세션 없음 | `AUTHENTICATION_REQUIRED` |
| 계정 통합 승인 | 요청 없음 | `MERGE_REQUEST_NOT_FOUND` |
| 계정 통합 승인 | 만료 | `MERGE_REQUEST_EXPIRED`, 상태 `expired` |
| 배포 smoke | Node 인증서 체인 신뢰 실패 | `UNABLE_TO_GET_ISSUER_CERT_LOCALLY`, NAS 인증서 체인 후속 점검 |
