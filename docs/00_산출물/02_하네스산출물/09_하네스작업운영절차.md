# 하네스 작업 운영 절차

## 1. 목적

세션 마무리, 브랜치 승급처럼 반복되는 프로젝트 운영 작업을 하네스 작업으로 등록하고, 실행 순서와 산출물을 추적 가능하게 관리한다.

| `00020902_002` | 브랜치 승급 | 사용자가 `#브랜치 승급`을 요청 | `dev` to `stg` 승급, `stg` to `main` 승급 | 승급 PR 또는 병합 기록 |

## 3. 세션 마무리 절차

`#세션 마무리`를 새로 정의하거나 절차를 변경하는 요청은 먼저 본 문서에 하네스 작업프로세스로 등록한 뒤, 등록된 절차에 따라 실행한다.

| ID | 순서 | 작업 | 처리 기준 |
| :--- | :---: | :--- | :--- |
| `00020903_001` | 1 | 이슈 등록 | 작업 배경, 목표, 범위, 완료 조건, 관련 문서를 포함해 GitHub 이슈를 생성한다. |
| `00020903_002` | 2 | 작업 리뷰 문서 작성 | 이번 작업 요약, 변경 문서, 검증 내용, 다음 작업 목표와 범위를 기록한다. |
| `00020903_003` | 3 | PR 생성 | 작업 브랜치를 push하고 `dev` 브랜치를 대상으로 PR을 생성한다. |
