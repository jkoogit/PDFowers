## 프로젝트 산출물과의 관계

- 하네스 산출물은 제품 요구사항을 대체하지 않는다.
- 하네스 산출물은 프로젝트 산출물의 요구사항, 설계, 아키텍처를 검증 가능한 실행 환경으로 변환한다.
- 중복되는 내용은 [프로젝트 산출물 작성 로드맵의 중복 검토 및 통합 방안](../01_프로젝트산출물/99_문서작성로드맵.md#2-중복-검토-및-통합-방안)을 따른다.
