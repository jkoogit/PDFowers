# 10. 리뷰관리

## 목적

신규 프로젝트에서 수행한 코드 리뷰, 문서 리뷰, 설계 리뷰, 정합성 점검, 회고를 관리한다.

## 초기화 정책

이 폴더는 초기화 대상이다. 기존 `참고_docs/10_리뷰관리`의 린트 결과, 리뷰 보고서, 회고, 심층 분석 문서는 이관하지 않는다.

신규 프로젝트에서 실제 작업이 발생한 뒤 새 리뷰 문서를 작성한다.

## 권장 폴더 구조

```text
10_리뷰관리/
├── README.md
├── 템플릿/
│   ├── 코드리뷰.md
│   ├── 문서리뷰.md
│   ├── 설계리뷰.md
│   └── 회고.md
└── YYYYMM/
    └── DD/
        └── YYMMDD_순번_리뷰구분_이슈번호_제목.md
```

## 리뷰 문서 권장 구조

```markdown
# 리뷰 제목

## 리뷰 대상

## 주요 발견사항

## 수정 필요사항

## 확인한 테스트

## 후속 조치
```

## 작성 규칙

- 리뷰는 신규 프로젝트 산출물에 대해서만 작성한다.
- 과거 참고 문서 분석은 리뷰가 아니라 [논리모순 검토 대장](../08_이슈관리/논리모순_검토대장.md#검토-항목) 또는 각 폴더 README의 검토 필요사항으로 남긴다.
- 리뷰 파일명에는 가능한 한 이슈 번호를 포함한다.
- `#세션마무리` 리뷰 문서에는 세션번호, 세션명, 작업 요약, 변경 파일, 검증 내용, 문서 현행화 대상, 관련 이슈/PR, 다음 작업 범위를 포함한다.
- 문서 정합성 리뷰는 링크, 폴더 번호, 정책 ID, ADR 상태를 함께 확인한다.
