## 정리한 워크플로

### #세션시작

- 원격 `dev`, `stg`, `main` 상태 확인
- 로컬 `main`과 `origin/main` 일치 여부 확인
- 작업트리 상태 확인
- 새 세션 작업 범위, 정책 결정 필요사항, 구체화 필요사항 정리

### #세션마무리

- 세션 작업 내용과 변경 파일 정리
- 심화학습 및 후속 검토 대상 선별
- 관련 문서 작성
- 이슈 생성
- 검증 후 커밋, push, PR 작성

### #브랜치승급

- `dev -> stg`, `stg -> main` 순서로 승급
- 각 승급을 PR로 처리
- 머지 메시지에 승급 PR 번호와 관련 원천 PR 번호 표시
- 승급 완료 후 `dev`, `stg`, `main` tree hash 일치 여부 확인
- 관련 이슈에 승급 PR, merge SHA, 검증 결과 기록

## 제한 사항

`skill-creator`의 `quick_validate.py`는 번들 Python 환경에 `PyYAML`이 없어 실행하지 못했다. 대신 스킬 파일의 필수 frontmatter와 트리거 문구를 수동으로 확인했다.

Windows PowerShell에서 UTF-8 파일을 기본 인코딩으로 읽을 때 한글이 깨져 보일 수 있다. `Select-String -Encoding UTF8` 또는 UTF-8 명시 읽기를 사용하면 트리거 문구는 확인된다.
