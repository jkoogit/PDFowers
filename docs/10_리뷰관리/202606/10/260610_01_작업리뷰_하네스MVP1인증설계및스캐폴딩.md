## 2. 작업 배경

1차 MVP 인증 개발을 시작하기 전에 하네스 기반 실제 프로젝트 구조를 확인하고, 구현에 필요한 설계 문서, ADR, 개발 명령어, 최소 인증 도메인 스캐폴딩을 준비했다.

현재 저장소에는 앱 소스와 `package.json`이 없고 `docs/` 중심 구조만 존재했다. 따라서 실제 하네스 생성물 분석 대신, 현재 상태를 명확히 기록하고 외부 패키지 없이 검증 가능한 Node.js 기본 테스트 기반 인증 도메인부터 시작했다.

## 6. 남은 결정과 주의사항

- 현재 PowerShell PATH에는 `npm`이 없어 번들 Node 직접 실행으로 검증했다.
- TypeScript, Vitest, Drizzle ORM은 아직 설치하지 않았다.
- REST API 서버, OpenAPI 생성, 실제 OAuth 제공자 연동은 다음 작업 범위다.
- 비밀번호 해시는 MVP1 도메인 스캐폴딩 단계에서 Node 내장 `scryptSync`를 사용했으며, 운영 기준은 추후 인증 보안 문서에서 강화한다.
