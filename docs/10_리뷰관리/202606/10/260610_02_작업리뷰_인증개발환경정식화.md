## 2. 작업 배경

이전 세션에서 인증 도메인 최소 스캐폴딩은 Node.js 기본 테스트 러너와 JavaScript 파일로 시작했다. 이번 세션은 인증 개발환경을 TypeScript/Vitest 기반으로 정식화하고, MVP1 인증 테스트 목록을 자동화 테스트와 맞추는 것이 목적이었다.

작업 중 로컬 PATH의 `node`가 WindowsApps 아래 Codex 앱 내부 실행 파일을 먼저 잡아 `Access is denied`가 발생했고, `npm`은 PATH에 등록되어 있지 않았다. 따라서 사용자 폴더에 Node/npm을 설치하고 PATH를 정리했다.

## 8. 남은 위험과 주의사항

- 현재 구현은 HTTP/API, DB, 실제 OAuth 제공자 연동 없이 도메인 순수 함수 중심이다.
- 비밀번호 해시는 Node 내장 `scryptSync`를 사용한다. 운영 보안 기준에서는 Argon2id 또는 bcrypt 적용 여부를 별도 검토해야 한다.
- Drizzle ORM은 아직 설치하지 않았다. 스키마와 migration은 다음 PR에서 DB 기준과 함께 확정해야 한다.
- Codex 앱 내부 셸은 부모 프로세스 PATH를 상속하므로, PATH 정리 후에는 앱 또는 터미널을 새로 열어야 자연스럽게 반영된다.
- 우분투 DB 서버의 PostgreSQL 포트는 현재 로컬 네트워크에 노출되어 있다. 오픈 전 보안정책 정비가 필요하다.
- PostgreSQL 백업은 아직 자동화되지 않았다. 현재는 백업 경로와 방향만 정리되어 있다.
- `jk` 사용자는 Docker 그룹에 추가하지 않았다. Docker 운영 명령은 현재 `sudo docker ...` 기준이다.
