## 5. 카카오 연동 검증 기록

| 항목 | 결과 |
| :--- | :--- |

| REST API 키 이름 | `PDFowers.rest-dev` |
| 로컬 Redirect URI | `http://localhost:4173/auth/kakao/callback` |
| 검수 서버 설정 상태 | `enabled=true`, `missing=[]`, `clientSecretConfigured=true` |
| 성공 응답 | `provider=kakao`, provider 식별자 수신, `MVP1-AUTH-T006=passed` |
| 토큰 저장 여부 | 저장하지 않음 |

## 6. 카카오 설정 시행착오와 결론

| 오류 | 원인 | 해결 |
| :--- | :--- | :--- |
| `KOE205` | 카카오 동의항목 미설정 상태에서 `account_email,profile_nickname` scope 요청 | 로컬 검수에서는 `KAKAO_SCOPE=`로 비우고, 동의항목 설정 후 scope 재활성화 |
| `KOE006` | Redirect URI를 JavaScript 키 화면에만 등록하고 REST API 키 화면에는 등록하지 않음 | `앱 설정 > 앱 > 플랫폼 키 > REST API 키 수정`의 `카카오 로그인 리다이렉트 URI`에 등록 |
| 토큰 교환 실패 가능성 | Client Secret ON인데 서버 env에 미반영 | `KAKAO_CLIENT_SECRET` 설정 후 검수 서버 재시작 |

결론:

- 서버 REST OAuth는 JavaScript 키가 아니라 REST API 키 설정을 따른다.
- Redirect URI는 서버가 사용하는 `KAKAO_REST_API_KEY`와 같은 REST API 키 화면에 등록해야 한다.
- 카카오 콘솔 설정 후에는 저장 버튼을 누르고, 로컬 검수 서버를 재시작해야 `.env` 변경이 반영된다.

## 10. 보안/운영 메모

- `.env`는 Git 제외 상태이며 민감정보를 커밋하지 않는다.
- 카카오 REST API 키와 Client Secret 원문은 문서/이슈/PR에 남기지 않는다.
- OAuth access token과 refresh token은 MVP1에서 저장하지 않는다.
- 운영/stg는 HTTPS 도메인과 Client Secret 활성화를 기본으로 한다.
- `localhost`는 PC 로컬 테스트에만 유효하다. 모바일 테스트는 실제 접근 가능한 HTTPS 도메인이 필요하다.
