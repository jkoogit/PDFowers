## 2. 주요 변경

1. Kakao Redirect URI 환경 분리
   - `APP_ENV=dev`에서는 `KAKAO_ALLOWED_REDIRECT_ORIGINS`에 등록된 요청 Host 기준으로 callback URI를 생성한다.
   - `APP_ENV=stg`, `APP_ENV=prd`에서는 기존처럼 `APP_BASE_URL + KAKAO_REDIRECT_PATH` 기준 고정 callback URI를 사용한다.
   - 허용되지 않은 Host는 request-host callback 대상으로 사용하지 않는다.

2. dev NAS IP 직접 접속 검증 보완
   - `http://192.168.219.112:4173`에서 Kakao 로그인을 시작하면 callback도 같은 origin인 `http://192.168.219.112:4173/auth/kakao/callback`을 사용하도록 했다.
   - NAS 컨테이너 내부 healthcheck용 `http://127.0.0.1:4173`도 허용 origin 예시에 포함했다.

3. Kakao callback 인증 UX 보완
   - callback 성공 시 JSON 응답 대신 검수화면 `/`으로 복귀한다.
   - callback 실패와 state mismatch도 오류 코드와 함께 검수화면으로 복귀한다.
   - 검수화면은 query string의 Kakao 결과를 읽어 상태 메시지를 표시하고, 새로고침 중복 표시를 막기 위해 query를 정리한다.

4. 문서 갱신
   - MVP1 잔여작업 문서에 이번 세션 완료 범위와 다음 세션 범위를 분리했다.
   - Kakao 검수 설정, 배포 운영 가이드, NAS 내부망 심화학습 문서에 `APP_ENV=dev` request-host 기준을 반영했다.
