# 카카오 간편로그인 검수 설정

## 구현 범위

- MVP1 검수 서버에 실제 카카오 OAuth 시작/콜백 엔드포인트를 추가한다.
- 검수화면에서 카카오 설정 상태와 실제 로그인 시작 버튼을 확인한다.
- 카카오 access token, refresh token, client secret은 DB에 저장하지 않는다.
- 콜백에서 받은 카카오 회원번호와 이메일/닉네임만 기존 MVP1 계정 도메인으로 정규화한다.

## 서버 엔드포인트

- `GET /auth/kakao/config-status`
  - 카카오 설정 가능 여부와 누락 환경변수를 반환한다.
- `GET /auth/kakao/start`
  - CSRF 방지용 `state` 쿠키를 만들고 카카오 인가 URL로 `302` 리다이렉트한다.
- `GET /auth/kakao/callback`
  - `code`, `state`를 검증한다.
  - 카카오 토큰 발급 API와 사용자 정보 API를 호출한다.
  - 기존 `kakao` identity가 있으면 로그인하고, 없으면 신규 OAuth 계정을 생성한다.

## 환경변수

로컬 검수 기본값은 `PORT=4173` 기준이다.

```dotenv
KAKAO_REST_API_KEY=카카오_개발자_콘솔_REST_API_키
KAKAO_REDIRECT_URI=http://localhost:4173/auth/kakao/callback
KAKAO_SCOPE=account_email,profile_nickname
# 카카오 앱에서 Client Secret을 활성화한 경우에만 설정
KAKAO_CLIENT_SECRET=
```

## 카카오 개발자 콘솔에서 필요한 정보

- 개인 카카오 계정으로 Kakao Developers에 로그인한다.
- 애플리케이션을 생성하거나 기존 앱을 선택한다.
- 앱 키에서 `REST API 키`를 확인한다.
- 카카오 로그인 기능을 활성화한다.
- Web 플랫폼 사이트 도메인에 `http://localhost:4173`을 등록한다.
- Redirect URI에 `http://localhost:4173/auth/kakao/callback`을 등록한다.
- 동의항목에서 닉네임과 이메일 사용 범위를 확인한다.
- 앱에서 Client Secret을 활성화했다면 값을 확인해 `KAKAO_CLIENT_SECRET`에만 설정한다.

## 개인 계정이 필요한 경우

다음 작업은 Codex가 대신 할 수 없고 카카오 개인 계정 로그인이 필요하다.

- Kakao Developers 앱 생성 또는 기존 앱 선택
- REST API 키 확인
- 카카오 로그인 활성화
- Web 플랫폼 도메인과 Redirect URI 등록
- 동의항목 설정 및 이메일 제공 권한 확인
- Client Secret 활성화 여부 확인

채팅이나 이슈에 Client Secret, 계정 비밀번호, 운영 앱 키를 남기지 않는다. 로컬 `.env` 또는 별도 비밀 관리 도구에만 저장한다.
