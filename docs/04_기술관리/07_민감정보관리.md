# 07. 민감정보 관리

## 목적

하네스 개발과 운영 과정에서 계정, 계좌, 개인정보, 시스템 설정, DB 계정, 인증키 같은 민감정보를 안전하게 관리하기 위한 기준을 정의한다.

## 민감정보 분류

| 분류 | 예시 | 문서 기록 방식 |
| :--- | :--- | :--- |
| 개인 계정 | 카카오/네이버/구글 로그인 계정 | 기록 금지 |
| OAuth 시크릿 | Client Secret, Refresh Token | 환경변수명만 기록 |
| DB 정보 | DB URL, 계정, 비밀번호 | 마스킹 |
| 시스템 설정 | Session Secret, JWT Secret | 환경변수명만 기록 |
| 계좌/결제 | 카드, 계좌, 결제수단 | 기록 금지 |
| 개인정보 | 이름, 이메일, 전화번호, 문서 원문 | 최소 수집, 마스킹 |

## 저장 위치 원칙

| 환경 | 저장 위치 |
| :--- | :--- |
| 로컬 개발 | `.env` 또는 `.env.local` |
| 예시 파일 | 저장소에 두지 않음. 필요한 키 이름은 본 문서에 기록 |
| NAS 배포 | NAS의 실제 `.env` 파일 또는 Container Station 환경변수 |
| Cloudtype 배포 | Cloudtype 환경변수/시크릿 |
| GitHub Actions | GitHub Secrets |
| 문서 | 마스킹된 항목 목록만 기록 |

## 금지사항

- 실제 Client Secret을 문서에 기록하지 않는다.
- DB 비밀번호를 이슈, 리뷰, 채팅, 커밋 메시지에 남기지 않는다.
- `.env.local`을 Git에 커밋하지 않는다.
- 운영 DB 계정을 로컬 개발에 재사용하지 않는다.
- 로그에 OAuth 토큰, 인증 코드, 세션 쿠키를 출력하지 않는다.

## 권장 운영

- 개발, 테스트, 운영 OAuth 앱을 분리한다.
- 개발, 테스트, 운영 DB 계정을 분리한다.
- 운영 계정은 최소 권한을 부여한다.
- 시크릿 노출이 의심되면 즉시 폐기하고 재발급한다.
- 2단계 인증을 가능한 모든 콘솔 계정에 적용한다.
- 프로젝트 전용 개발자 계정 또는 조직 계정을 우선 사용한다.

## 환경변수 대장 예시

| 이름 | 용도 | 필수 | 민감정보 | 예시 |
| :--- | :--- | :---: | :---: | :--- |
| `DATABASE_URL` | DB 접속 URL | Y | Y | `postgresql://****` |
| `SESSION_SECRET` | 세션 서명 키 | Y | Y | `****` |
| `COOKIE_SECURE` | HTTPS 쿠키 전용 여부 | Y | N | `false` |
| `COOKIE_DOMAIN` | 쿠키 도메인 | N | N | `localhost` |
| `OAUTH_KAKAO_CLIENT_ID` | 카카오 OAuth 앱 ID | Y | N | `dummy-kakao-client-id` |
| `OAUTH_KAKAO_CLIENT_SECRET` | 카카오 OAuth 시크릿 | Y | Y | `****` |
| `OAUTH_KAKAO_CALLBACK_URL` | 카카오 OAuth callback URL | Y | N | `http://localhost:3000/auth/kakao/callback` |
| `OAUTH_NAVER_CLIENT_ID` | 네이버 OAuth 앱 ID | Y | N | `dummy-naver-client-id` |
| `OAUTH_NAVER_CLIENT_SECRET` | 네이버 OAuth 시크릿 | Y | Y | `****` |
| `OAUTH_NAVER_CALLBACK_URL` | 네이버 OAuth callback URL | Y | N | `http://localhost:3000/auth/naver/callback` |
| `OAUTH_GOOGLE_CLIENT_ID` | 구글 OAuth 앱 ID | Y | N | `dummy-google-client-id` |
| `OAUTH_GOOGLE_CLIENT_SECRET` | 구글 OAuth 시크릿 | Y | Y | `****` |
| `OAUTH_GOOGLE_CALLBACK_URL` | 구글 OAuth callback URL | Y | N | `http://localhost:3000/auth/google/callback` |
| `APP_BASE_URL` | 앱 기본 URL | Y | N | `http://localhost:3000` |
| `NODE_ENV` | Node 실행 환경 | Y | N | `development` |

`.env`, `.env.local`, `.env.development`, `.env.production`처럼 실제 값이 들어가는 파일은 Git에 커밋하지 않는다. 개발, 검증, 운영 서비스는 배포 시스템에서 `DATABASE_URL` 등 필요한 값을 환경변수로 주입한다.
