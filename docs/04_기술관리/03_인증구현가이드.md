# 03. 인증 구현 가이드

## 목적

하네스 기반 신규 프로젝트에서 ID 계정, 카카오/네이버/구글 간편로그인, 로그인 수단 연결, 계정 통합을 구현하기 위한 기술 기준을 정리한다.

## 인증 범위

| 구분 | MVP 처리 |
| :--- | :--- |
| ID 계정 | 구현 |
| 카카오 로그인 | 구현 후보 |
| 네이버 로그인 | 구현 후보 |
| 구글 로그인 | 구현 후보 |
| 휴대폰 본인인증 | 제외 |
| 실명확인 | 제외 |

## 환경변수

실제 값은 문서에 기록하지 않는다.

```text
KAKAO_CLIENT_ID=
KAKAO_CLIENT_SECRET=
KAKAO_REDIRECT_URI=

NAVER_CLIENT_ID=
NAVER_CLIENT_SECRET=
NAVER_REDIRECT_URI=

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GOOGLE_REDIRECT_URI=

SESSION_SECRET=
DATABASE_URL=
```

## OAuth 콜백 처리 원칙

1. 제공자 OAuth 인증을 완료한다.
2. 토큰 교환 후 제공자 사용자 정보를 조회한다.
3. 제공자 사용자 고유 ID를 `provider_user_id`로 저장한다.
4. 이메일은 회원가입/로그인 인증, 사용자 화면 인증, 계정 식별 보조, 작업 알림 발송 대상으로 사용하되 자동 통합의 단독 근거로 사용하지 않는다.
5. `(provider, provider_user_id)` 기준으로 내부 연결 이력을 조회한다.

## 로그인 처리

```text
provider_user_id가 기존 AuthIdentity에 있음
  -> 연결된 user_srno로 로그인

provider_user_id가 없음
  -> 로그인 흐름이면 회원가입으로 안내
  -> 회원가입 흐름이면 신규 User 생성
  -> AuthIdentity 생성
  -> 로그인 또는 가입 완료
```

ID/이메일 로그인은 시스템 설정에 따라 이메일 인증을 필수 또는 선택으로 처리한다.

- 이메일 인증 필수 설정이면 회원가입 시 이메일 인증을 완료해야 하며, ID 로그인은 이메일 인증 완료 계정만 허용한다.
- 이메일 인증 선택 설정이면 회원가입 시 이메일 인증 옵션과 알림 수신 안내를 제공하고, ID 로그인은 이메일 미인증 상태에서도 허용할 수 있다.
- 간편로그인은 제공자 인증 결과를 사용하므로 시스템 이메일 인증 설정과 관계없이 이메일 인증을 생략한다.

## 로그인 수단 연결 처리

```text
현재 로그인 user_srno = A01
연결 요청 provider_user_id = kakao01

kakao01 연결 이력 없음
  -> A01에 연결

kakao01이 A01에 이미 연결됨
  -> AUTH_IDENTITY_ALREADY_LINKED

kakao01이 A02에 연결됨
  -> ACCOUNT_MERGE_REQUIRED
  -> 대상 계정에 계정 통합 요청 발송
  -> 대상 계정 로그인 후 통합 정보 확인 및 동의
```

## 계정 통합 구현 기준

- 통합은 서버 트랜잭션으로 처리한다.
- 대표 계정을 정하고, 보조 계정 데이터를 대표 계정으로 이전한다.
- `AuthIdentity.user_srno`를 대표 계정으로 변경한다.
- 보조 `User.status`는 `merged`로 변경한다.
- `merged_into_user_srno`에 대표 계정 내부 식별자를 저장한다.
- 통합 이벤트는 `Audit` 도메인에 기록한다.

## 보안 기준

- Client Secret은 서버에서만 사용한다.
- OAuth `state` 값을 사용하여 CSRF를 방지한다.
- Redirect URI는 제공자 콘솔에 등록된 값과 정확히 일치시킨다.
- 로그에 토큰, Client Secret, Authorization Code를 남기지 않는다.
- 마지막 로그인 수단은 해제할 수 없게 한다.

## 테스트 시나리오

| 시나리오 | 기대 결과 |
| :--- | :--- |
| 신규 카카오 로그인 | 신규 User와 AuthIdentity 생성 |
| 기존 카카오 로그인 | 기존 User로 로그인 |
| 로그인 상태에서 미연결 구글 연결 | 현재 User에 Google AuthIdentity 연결 |
| 로그인 상태에서 다른 계정의 카카오 연결 시도 | `ACCOUNT_MERGE_REQUIRED` 반환 |
| 대상 계정의 계정 통합 승인 | 대표 User로 데이터 이전, 보조 User는 `merged` |
| 이메일 동일 계정 발견 | 자동 통합하지 않음 |
