# 06. 개발 명령어

## 목적

하네스 기반 PDFowers 개발자가 로컬에서 반복 실행할 명령을 정리한다. 현재 저장소에는 앱 소스가 없으므로 즉시 실행 가능한 명령과 앱 스캐폴딩 이후 사용할 명령을 분리한다.

## 현재 즉시 실행 가능한 명령

| 목적 | 명령 | 기준 |
| :--- | :--- | :--- |
| Git 상태 확인 | `git status --short --branch` | 작업 브랜치와 변경 파일을 확인한다. |
| 문서 공백 검사 | `git diff --check` | Markdown 변경의 trailing whitespace를 확인한다. |
| 파일 목록 확인 | `rg --files` | 저장소 문서와 소스 생성 여부를 확인한다. |
| Node 테스트 | `node --test` | 현재 최소 인증 도메인 테스트를 실행한다. |
| 번들 Node 테스트 | `& 'C:\Users\jkoog\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' --test` | PowerShell PATH에 `npm` 또는 `node`가 없을 때 Codex 번들 Node로 테스트를 실행한다. |

## 앱 스캐폴딩 이후 표준 명령

| 목적 | 명령 | 기준 |
| :--- | :--- | :--- |
| 의존성 설치 | `npm install` | `package-lock.json`을 생성 또는 갱신한다. |
| 개발 서버 | `npm run dev` | 로컬 API 또는 웹 서버를 실행한다. |
| 단위/통합 테스트 | `npm test` | 도메인 규칙과 인증 흐름 테스트를 실행한다. 현재 `package.json`의 `test` 스크립트는 `node --test`를 호출한다. |
| 테스트 감시 | `npm run test:watch` | 개발 중 변경 파일 기준 테스트를 반복 실행한다. |
| 린트 | `npm run lint` | 코드 스타일과 정적 규칙을 확인한다. |
| 타입 검사 | `npm run typecheck` | TypeScript 타입 오류를 확인한다. |
| 빌드 | `npm run build` | 배포 가능한 산출물을 생성한다. |

## DB와 ORM 명령 후보

Drizzle ORM 도입 후 다음 명령을 표준 후보로 둔다.

| 목적 | 명령 | 기준 |
| :--- | :--- | :--- |
| 마이그레이션 생성 | `npm run db:generate` | 스키마 변경에서 SQL 마이그레이션을 생성한다. |
| 마이그레이션 적용 | `npm run db:migrate` | 로컬 또는 테스트 DB에 마이그레이션을 적용한다. |
| DB 스튜디오 | `npm run db:studio` | 로컬 개발 중 스키마와 데이터를 확인한다. |

## 테스트 게이트

MVP1 인증 PR은 최소한 다음 명령을 통과해야 한다.

```text
npm test
npm run typecheck
npm run lint
```

앱 스캐폴딩 직후 외부 패키지가 없는 최소 상태에서는 `npm test`부터 통과시키고, TypeScript와 린트 도구 설치 후 나머지 게이트를 활성화한다.

## 환경변수 기준

| 변수 | 목적 | 민감정보 여부 |
| :--- | :--- | :---: |
| `DATABASE_URL` | PostgreSQL 연결 | 예 |
| `SESSION_SECRET` | 서버 세션 서명 | 예 |
| `OAUTH_KAKAO_CLIENT_ID` | 카카오 OAuth 앱 ID | 아니오 |
| `OAUTH_KAKAO_CLIENT_SECRET` | 카카오 OAuth Secret | 예 |
| `OAUTH_NAVER_CLIENT_ID` | 네이버 OAuth 앱 ID | 아니오 |
| `OAUTH_NAVER_CLIENT_SECRET` | 네이버 OAuth Secret | 예 |
| `OAUTH_GOOGLE_CLIENT_ID` | 구글 OAuth 앱 ID | 아니오 |
| `OAUTH_GOOGLE_CLIENT_SECRET` | 구글 OAuth Secret | 예 |

민감정보 원문은 문서, 이슈, PR, 테스트 로그에 기록하지 않는다.
