# 09. 심화학습

## 목적

프로젝트 구현에 필요한 기술 개념, 실험 결과, 학습 노트를 관리한다. 이 폴더는 확정 정책이나 설계 문서가 아니라 학습과 판단 보조 자료를 담는다.

## 기존 참고 문서에서 유지할 핵심

| 주제 | 유지할 내용 |
| :--- | :--- |
| tRPC | 서버 타입을 클라이언트에서 공유하여 API 스키마 중복을 줄이는 방식 |
| CORS | 브라우저-서버 통신에서만 필요한 제약이며, 서버-서버 통신과 구분해야 함 |
| MSA | 향후 서비스 분리 시 도메인 경계와 통신 방식을 미리 고려 |

## 초기화 기준

기존 학습 문서는 주제 후보로만 승계한다. 신규 프로젝트에서 실제로 채택한 기술이 아니면 확정 설계 문서로 연결하지 않는다.

## 검토 필요사항

- tRPC는 기존 문서에서 강하게 추천되지만 하네스 기본 구조와 맞는지 확인해야 한다.
- PDF 처리 관련 학습은 실제 샘플 PDF와 라이브러리 PoC 결과를 함께 기록해야 한다.
- CORS 정책은 배포 도메인이 정해진 뒤 운영 설정으로 승격한다.
