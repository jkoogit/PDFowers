# 코드관리

## 1. 목적

PDFowers 프로젝트의 소스 코드 품질, 가독성, 유지보수성을 극대화하기 위해 객체지향 프로그래밍(OOP), 도메인 주도 설계(DDD), 클린/헥사고날 아키텍처 원칙 및 네이밍, 주석 규칙을 관리한다.

## 3. 핵심 아키텍처 원칙

1. **도메인 중심 캡슐화 (Domain Encapsulation)**: 비즈니스 규칙과 상태 변경은 도메인 엔티티 내부에서 스스로 검증하고 수행한다.
2. **포트와 어댑터 분리 (Hexagonal / Ports & Adapters)**: 도메인은 외부 프레임워크(Express, Drizzle 등)에 의존하지 않고 인터페이스(Port)로만 소통한다.
3. **도메인 중심 테스트 (Domain-Centric Testing)**: 외부 DB나 네트워크 없이 순수 메모리 상에서 초고속으로 비즈니스 로직을 검증한다.
