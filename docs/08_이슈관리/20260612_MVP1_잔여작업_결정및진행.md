## 계정 통합 UX 보완 기준

1. 요청 계정이 다른 계정에 연결된 OAuth 식별자를 연결하려 하면 자동 통합하지 않는다.
2. MVP1 대표 계정은 요청 계정으로 고정한다.
3. 요청자는 안내 메시지를 확인한 뒤 `통합 요청 보내기` 버튼을 눌러 요청을 생성한다.
4. 사용자정보 화면에는 통합계정 목록을 표시한다. 통합정보가 한 건도 없으면 목록을 표시하지 않는다.
5. 요청자 목록 상태는 `요청`, `반려`, `완료`로 표시한다.
6. 대상자 목록 상태는 `요청`, `거절`로 표시한다. 승인 후 대상 계정은 로그인을 제한한다.
7. 대상자 목록에는 `승인`, `거절`, `삭제` 버튼을 표시한다.
8. 대상자가 삭제하면 자동 거절 처리한다.
9. 요청자가 통합정보를 삭제하면 대상자 목록에서도 삭제한다.
10. 통합 여부와 관계없이 요청자는 통합정보를 삭제할 수 있다.
11. 대상 계정은 승인 전 다음 내용을 확인해야 한다.
   - 이전될 로그인 제공자
   - 이전 후 대상 계정이 `merged` 상태가 된다는 점
   - 되돌리기 어려운 작업이라는 점
12. 화면에서는 provider user id를 전체 노출하지 않고 일부 마스킹한다.
13. 승인, 취소, 만료, 중복 승인 실패는 모두 사용자에게 상태 메시지로 표시한다.
14. 요청 생성 시 대상 계정에 알림을 보내고, 승인 완료 시 요청/대상 양쪽에 알림을 보낸다.
15. 승인 확인 메시지는 다음 문구를 사용한다.

```text
해당 계정의 자료와 활동은 A계정으로 이동하고 계정이 잠깁니다.
동의하시겠습니까?
```

16. 통합 완료 또는 잠긴 보조 계정 로그인 시 다음 문구를 표시한다.

```text
해당 계정의 자료는 A계정으로 통합되었습니다.
A계정으로 로그인하시기 바랍니다.
(등록문서 0건, 공유문서 0건)
```

## 2026-06-17 Kakao 간편로그인 마무리 기준

현재 MVP1 우선 마무리 작업은 Kakao 간편로그인을 로컬, IntelliJ, dev NAS, stg 배포에서 같은 기준으로 검증 가능하게 만드는 것이다.

| 작업 | 기준 |
| :--- | :--- |
| dev 서비스 Kakao 화면 이동 | `https://jkok2.myqnapcloud.com:4443/auth/kakao/start`가 Kakao authorize URL로 redirect |
| Codex 로컬/IntelliJ | `APP_BASE_URL=http://localhost:4173`, Redirect URI `http://localhost:4173/auth/kakao/callback` |
| dev NAS | `APP_BASE_URL=https://jkok2.myqnapcloud.com:4443`, Redirect URI `https://jkok2.myqnapcloud.com:4443/auth/kakao/callback` |
| stg | `APP_BASE_URL=https://fowersstg.pdfrend.com`, Redirect URI `https://fowersstg.pdfrend.com/auth/kakao/callback` |
| 배포 후 자동 확인 | `npm run review:kakao-smoke -- --base-url <환경 URL>` |
| 내부망 도메인 | hairpin NAT 또는 내부 DNS/hosts로 같은 도메인명을 NAS 내부 IP에 매핑 |

dev NAS 내부망에서는 브라우저 주소를 IP로 바꾸지 않는다. 내부 DNS 또는 hosts만 `jkok2.myqnapcloud.com -> 192.168.219.112`로 처리해 브라우저 주소, 서버 Redirect URI, 카카오 콘솔 Redirect URI가 같은 도메인으로 유지되게 한다.

### 추가 조치 범위

1. dev, stg, prd 도메인과 NAS 연결 상태를 확정한다.
2. Kakao Developers REST API Redirect URI에 환경별 callback URI를 등록한다.
3. NAS 후보 환경의 `.env`를 `APP_ENV`, `APP_BASE_URL`, `DATABASE_URL`, `SESSION_SECRET`, `KAKAO_*`, `SMTP_*` 기준으로 분리한다.
4. 운영자가 Kakao 실제 로그인 완료, callback 복귀, 세션 발급, 계정 통합 UX 표시를 수동 검증하고 결과를 리뷰 문서에 기록한다.
5. Node smoke test에서 인증서 오류가 발생하면 도메인 인증서 full chain을 먼저 확인하고, 필요 시 실행 환경에서만 `NODE_EXTRA_CA_CERTS`를 사용한다.
