## 계정 통합 UX 보완 기준

1. 요청 계정이 다른 계정에 연결된 OAuth 식별자를 연결하려 하면 자동 통합하지 않는다.
2. MVP1 대표 계정은 요청 계정으로 고정한다.
3. 대상 계정은 승인 전 다음 내용을 확인해야 한다.
   - 이전될 로그인 제공자
   - 이전 후 대상 계정이 `merged` 상태가 된다는 점
   - 되돌리기 어려운 작업이라는 점
4. 화면에서는 provider user id를 전체 노출하지 않고 일부 마스킹한다.
5. 승인, 취소, 만료, 중복 승인 실패는 모두 사용자에게 상태 메시지로 표시한다.
6. 요청 생성 시 대상 계정에 알림을 보내고, 승인 완료 시 요청/대상 양쪽에 알림을 보낸다.

## 2026-06-17 Kakao 간편로그인 마무리 기준

현재 MVP1 우선 마무리 작업은 Kakao 간편로그인을 로컬, IntelliJ, dev NAS, stg 배포에서 같은 기준으로 검증 가능하게 만드는 것이다.

| 작업 | 기준 |
| :--- | :--- |
| dev 서비스 Kakao 화면 이동 | `https://jkok2.myqnapcloud.com:4443/auth/kakao/start`가 Kakao authorize URL로 redirect |
| Codex 로컬/IntelliJ | `APP_BASE_URL=http://localhost:4173`, Redirect URI `http://localhost:4173/auth/kakao/callback` |
| dev NAS | `APP_BASE_URL=https://jkok2.myqnapcloud.com:4443`, Redirect URI `https://jkok2.myqnapcloud.com:4443/auth/kakao/callback` |
| stg | `APP_BASE_URL=https://fowersstg.pdfrend.com`, Redirect URI `https://fowersstg.pdfrend.com/auth/kakao/callback` |
| 배포 후 자동 확인 | `npm run review:kakao-smoke -- --base-url <환경 URL>` |
| 내부망 도메인 | hairpin NAT 또는 내부 DNS/hosts로 같은 도메인명을 NAS 내부 IP에 매핑 |

dev NAS 내부망에서는 브라우저 주소를 IP로 바꾸지 않는다. 내부 DNS 또는 hosts만 `jkok2.myqnapcloud.com -> 192.168.219.112`로 처리해 브라우저 주소, 서버 Redirect URI, 카카오 콘솔 Redirect URI가 같은 도메인으로 유지되게 한다.
