# 20260608 Notion 참고문서 비교 검토

## 목적

초기 작업 내용이 담긴 Notion 참고문서를 주제별로 정리하고, 현재 `docs/` 문서에 정의된 내용과 비교하여 누락/보완 후보를 식별한다.

원문 기준 주제별 분석과 비교 상태는 [20260608 Notion 참고문서 비교 검토 원문정리](./20260608_notion_참고문서_비교검토_원문정리.md)에서 관리한다.

## 서비스 개요

- **Frontend (브라우저)**
    - 회원가입
    - 문서관리 : 카테고리별 문서 목록 조회, 업로드, 복사, 수정, 삭제
        - 루트카테고리는 ‘이름’, ‘공유문서’ 두개로 구성
        - ‘공유문서’(삭제, 수정 불가) 고정 카테고리 내 하위카테고리 정의
        - 문서 상세화면 관리 : 제목,(필수), 출판사, 저자, 역자, 발행일자, 가격, 페이지, 도서링크, 구매링크, 부가링크, ISBN, 비고
        - 편집속성
            - 북마크 타이틀 포멧 : [페이지번호]_[가까운앞목차명(목차없으면 책제목)]
        - 버전목록 + 변경이력버튼
            - 변경이력 클릭시 팝업으로 작업이력 조회
        - 문서기능
            - 공유 : 공유설정팝업 표시
            - 삭제 : 문서 삭제
        - 보기모드 : 목록, 썸네일
    - Draft 작업 관리
        - Draft 목록 : 작업자정보, 작성일시, 작업내용(json 목록 팝업 확인)
        - 삭제, 머지 버튼 처리
            - 삭제 : Draft 삭제
            - 머지 : 해당문서 최종버전에 Draft 작업 반영된 내용 미리 보기용 팝업 표시
                - 주석 좌표/페이지 구조가 적합한지 유효성 체크
                - 반영 버튼으로 해당문서에 Draft 작업내용 반영
                - 반영 후 Draft 삭제
    - 공유링크 관리 : 링크추가, 수정, 삭제
        - [공유관리], [사용관리] 탭화면구성
            1. 공유관리 : 등록한 공유링크 목록 표시
                1. 공유링크 등록 : 등록팝업 표시
                2. 목록처리기능 :  
                    1. 표시정보 : 공유대상, 공유기간, 공유권한 표시, 공유일시, 변경일시
                    2. 수정(등록화면에 수정정보 조회한 팝업표시)
                    3. 삭제(공유개시 전인 경우 데이터 삭제, 공유개시된 경우 권한회수 및 삭제여부 Y처리)
        - 공유링크추가 속성
            - 공유대상 : 카테고리(하위문서 전체),문서(대상문서 전체버전),버전(대상문서 특정버전 - 이후버전 권한적용)
            - 공유기간 : 무제한, 기간제한(시간,일,주,개월,년), 날짜제한(종료일시)
            - 공유권한 : 읽기, 주석쓰기, 자기주석편집, 전체주석편집, 댓글쓰기, 댓글편집
                - 생성위치 : 카테고리 영역 공유버튼, pdf영역 파일공유버튼, 버전 공유버튼
            - 공개읽기 여부
        1. 링크를 받은 사용자가 공유링크를 클릭하면
            1. 로그인 안한경우, 공개읽기 모드인 경우만 문서를 읽을수 있음
                1. 별도의 공개일기 문서뷰어 페이지 필요
            2. 로그인하면 공유권한에 따른 문서접근을 통해 작업을 할수 있음
            3. 로그인 안하고 문서를 본다음 로그인을 하면 권한모드로 접속하게 됨
                
                이때 링크로 들어와서 로그인할때까지 사이트에 머무는 동안 공유링크 정보를 유지 필요
                
        2. 공유받은 사람이 로그인하고 문서를 열면
            1. 공유가 개시됨
            2. 기간이 지나면 공유가 종료되고 문서 접근 권한이 없어짐
            3. 그래도 공유자가 로그인 해서 공유했던 이력은 조회할수 있어야함 (문서는 조회 못함)
                1. 공유이력화면에서는 공유자, 공유조건을 조회하고 개시일과 최종 작업일 함깨표시
                2. 한 문서에 여러 공유링크가 생길 수 있음
                3. 다만 읽기권한으로 공유한 상태에서 쓰기권한으로 문서가 다시 공유 되면
                    1. 최종 공유조건인 쓰기권한으로 설정됨.(목록에는 둘다 표시)
                4. 쓰기권한으로 공유된 문서를 다시 폴더공유를 통해 읽기권한 공유링크가 생성되면 최종 공유링크를 통해 읽기권한이 적용되고
                    1. 앞서 발생한 해당문서의 쓰기권한 공유는 종료됨
        3. 링크대상이 폴더처럼 여러 문서를 대상으로 하는 경우도 있지만 
        시스템 내부에서는 개별문서에 대한 공유권한을 관리해야 함.
            1. 나중에 다른 공유 정책으로 일부 문서의 권한이 변경될 수 있음
        4. 소유자의 주석과 공유자의 주석을 구분하고 주석소유권한에 따른 처리가 필요한 만큼
            1. 작성자별 주석 검색기능 필요
                1. 작성자 주석 일괄 삭제 필요
                2. 주석 검색시 작성자, 주석구분, text 검색 필요 - 페이지내 검색, 문서내 검색 범위구분 검색 필요
            2. 공유된 문서에서 작업시 누가 작성한 주석인지 확인이 필요한 상황을 위해 작성자 표시 버튼을 만들어서
                1. 작성자 표시 버튼 체크시 주석끝에 작성자명, 아바타이미지를 라벨로 표시
                2. 작성자 표시 버튼 체크를 하지 않더라도 주석에 마우스를 가져가면 라벨을 표시
                    1. pc는 마우스 오버, 모바일은 롱프레스
        5. 보안 : 공유문서 편집 중 공유권한 변경시 반영
            1. 편집권한에서 읽기권한으로 변경시 편집모드에서 읽기모드로 즉시 전환하고 메시지표시
    - PDF 뷰어
        - 모드 전환: PDF 모드(사이드뷰+작업뷰) / 읽기 모드(사이드뷰+읽기뷰)
        - 사이드뷰 : 접기/펴기/고정 기능
            - 시스템 설정 ‘멀티문서 유형’ 항목 ‘사이드바 표시 선택시 열려있는 문서 썸네일, 제목 표시
                - 멀티문서 유형 ‘미사용, 탭 표시’ 선택시 탭 숨김

## 📂 리소스 관리 흐름

1. **업로드**
    - 파일명을 기준으로 소유문서 중 업로드 대상문서 추천
    - 카테고리를 선택하여 대상문서를 선택하여 해당문서의 최종버전으로 업로드
        - 특정버전 선택시 하위 버전으로 라벨링
            - 예) 새문서 : 1.0 / 1.0 버전 선택시 1.1 / 미선택 : 최종 버전 +1.0
    - PDF 업로드 시 자동으로 문서 리소스 추출
        - 페이지별 이미지 추출(book.001~book400.jpg)
        - OCR json
        - 주석 및 목차 json
2. **조회**
    - 브라우저에서 특정 페이지 요청 시 → 해당 페이지 이미지 + OCR + 주석 JSON 병합 후 렌더링.
    - 모드별 표시:
        - PDF 모드: 원본 PDF 페이지 표시(옵션에 따라 주석 감추기)
        - 읽기 모드: JSON 기반 주석 오버레이 표시
        - OCR 편집 모드 : 주석을 제외한 OCR 적용화면을 표시하고 OCR text의 위치를 조정하거나 COR text를 추가, 수정, 삭제
    - 최종버전으로 문서를 열고
        - 수정 발생시 임시버전 채번(최종버전+1)
        - 동시작업자 발생 시 임시버전 공유(최종버전+1 문서를 작업)
        - 최종버전이 아닌 특정버전의 문서를 수정할 경우 다른이름으로(별도문서) 저장하고 버전은 해당버전 이후로 채번
3. **목차 기능**
    - 목차 import 및 export, 항목 화면 링크위치 지정
    - 목차 선택 시 해당 페이지로 이동.
4. **주석 편집/저장**
    - 페이지별 주석 수정 시 즉시 JSON 저장.
    - 저장 시 히스토리 기록 → 롤백 가능.(동시작업 없을 경우 )
