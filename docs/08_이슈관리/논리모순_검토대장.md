# 논리모순 검토 이슈 대장

## 목적

기존 `참고_docs`를 하네스 기반 신규 프로젝트 문서로 전환하는 과정에서 발견한 모순, 불확정 전제, 재검토 항목을 이슈관리 업무로 관리한다.

이 문서는 확정 문서가 아니라 검토 이슈 대장이다. 검토가 완료된 항목은 관련 정책, 기획, 설계, 기술, 의사결정 문서에 반영한다.

## 처리 규칙

- 수용 항목은 신규 문서 체계에 반영된 것으로 보고, 후속 상세 문서 작성 시 동일 기준을 유지한다.
- 검토 필요 항목은 해결 전까지 관련 내용을 확정 문서에 단정형으로 쓰지 않는다.
- 결정이 내려지면 `06_의사결정관리`에 ADR을 작성하고, 관련 README 또는 상세 문서를 갱신한다.
- 이 문서의 상태는 `검토 필요`, `수용`, `결정 완료`, `반영`, `보류` 중 하나로 관리한다.
