# 08. 이슈관리

## 목적

신규 프로젝트 진행 중 발생하는 기능 요청, 버그, 작업 계획, 장애, 검토 사항을 관리한다.

## 초기화 정책

이 폴더는 초기화 대상이다. 기존 `참고_docs/08_이슈관리`의 이슈 기록, 실행 계획, 과거 완료 상태는 이관하지 않는다.

신규 프로젝트의 첫 이슈부터 새로 작성한다. 단, 기존 문서 전환 과정에서 발견한 논리모순과 검토 필요사항은 이슈관리 업무로 보고 [논리모순_검토대장.md](./논리모순_검토대장.md)에 관리한다.

## 권장 폴더 구조

```text
08_이슈관리/
├── README.md
├── 논리모순_검토대장.md
├── 템플릿/
│   ├── 기능개발이슈.md
│   ├── 버그리포트.md
│   └── 검토이슈.md
└── YYYYMM/
    └── DD/
        └── YYMMDD_순번_이슈번호_제목.md
```

## 이슈 문서 권장 구조

```markdown
# 이슈 제목

## 배경

## 목표

## 범위

## 완료 조건

## 관련 문서

## 진행 기록
```

## 작성 규칙

- 문서 파일명은 신규 프로젝트 이슈 번호가 생긴 뒤 확정한다.
- 과거 이슈 번호를 재사용하지 않는다.
- 작업 중 발견한 문서 모순은 먼저 `docs/08_이슈관리/논리모순_검토대장.md`에 등록한다.
- 완료 조건은 테스트 또는 확인 가능한 산출물로 쓴다.
