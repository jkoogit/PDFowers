# 01. 시스템 정책

## 목적

PDFrend 신규 프로젝트의 서비스 운영, 인증, 계정, 데이터 관리 기준을 정의한다. 본 문서는 하네스 기반 구현 전 정책 기준이며, 세부 구현은 설계/기술 문서와 ADR에서 보완한다.

## 1. 회원 및 인증 정책

### Policy-AUTH-001: 내부 회원 식별자

- 회원의 최종 식별자는 외부 로그인 계정이 아니라 서비스 내부 `user_id`다.
- `user_id`는 UUID 사용을 기본 후보로 한다.
- 카카오, 네이버, 구글 계정은 회원을 식별하는 본체가 아니라 로그인 수단이다.

### Policy-AUTH-002: 본인인증 제외

- 휴대폰 본인확인, 실명확인, 주민등록 기반 본인인증은 비용 문제로 MVP 범위에서 제외한다.
- 간편로그인은 법적 동일인 인증으로 사용하지 않는다.
- 서비스는 간편로그인을 통해 "해당 외부 계정에 접근 가능한 사용자"만 확인한다.

### Policy-AUTH-003: 간편로그인 제공자

- MVP 후보 간편로그인 제공자는 카카오, 네이버, 구글이다.
- 각 제공자는 OAuth 또는 OIDC 기반으로 연동한다.
- 제공자별 사용자 고유 식별자는 `(provider, provider_user_id)`로 관리한다.

### Policy-AUTH-004: 이메일 자동 통합 금지

- 이메일, 이름, 전화번호가 같다는 이유만으로 내부 계정을 자동 통합하지 않는다.
- 외부 제공자가 반환하는 이메일은 미제공, 변경, 비공개, 재사용 가능성이 있으므로 계정 통합의 단독 근거로 사용하지 않는다.
- 이메일은 알림, 표시, 사용자 안내를 위한 보조 정보로만 사용한다.

### Policy-AUTH-005: 간편로그인 연결

- 사용자가 로그인한 상태에서 추가 간편로그인을 등록할 수 있다.
- 연결하려는 `(provider, provider_user_id)`가 어떤 내부 계정에도 연결되어 있지 않으면 현재 로그인한 `user_id`에 연결한다.
- 연결하려는 `(provider, provider_user_id)`가 다른 내부 계정에 이미 연결되어 있으면 자동 연결하지 않고 계정 통합 절차로 전환한다.

### Policy-AUTH-006: 계정 통합

- 계정 통합은 사용자의 명시적 동의가 있을 때만 수행한다.
- 동일한 벤더 계정에 대한 OAuth 인증을 성공한 경우, 두 내부 계정에 대한 접근권이 확인된 것으로 보고 통합 후보로 제시할 수 있다.
- 통합 시 대표 계정을 선택하고, 문서, 주석, 공유 권한, 설정, 감사 로그의 이전 범위를 명확히 안내한다.
- 병합되는 계정은 즉시 물리 삭제하지 않고 `merged` 상태와 `merged_into_user_id`를 남긴다.

### Policy-AUTH-007: 마지막 로그인 수단 보호

- 사용자는 여러 로그인 수단을 연결할 수 있다.
- 마지막 남은 로그인 수단은 해제할 수 없다.
- 로그인 수단 연결, 해제, 통합은 감사 로그에 기록한다.

## 2. 민감정보 관리 정책

### Policy-SEC-001: 비밀값 저장 금지

- 계정 비밀번호, OAuth Client Secret, DB 비밀번호, 인증키, 계좌 정보, 개인정보 원문은 Git, 문서, 이슈, 리뷰, 대화 기록에 저장하지 않는다.
- 문서에는 환경변수명, 용도, 필수 여부, 민감정보 여부만 기록한다.
- 예시 값은 실제 값처럼 보이지 않는 더미 값만 사용한다.

### Policy-SEC-002: 환경별 시크릿 분리

- 로컬, 테스트, 운영 환경의 OAuth 앱과 DB 계정은 분리한다.
- 로컬은 `.env.local`, 배포 환경은 Cloudtype 환경변수/시크릿, CI/CD는 GitHub Secrets 사용을 기본 후보로 한다.
- 운영 시크릿은 최소 권한 계정으로 발급하고, 노출 의심 시 즉시 회전한다.

## 3. 스토리지 및 용량 정책

- 신규 가입 사용자 기본 업로드 용량은 정책으로 관리한다.
- 공유받은 문서는 수신자의 업로드 용량에 포함하지 않는다.
- NAS 스토리지와 원격지 Ubuntu 스토리지는 테스트 운영을 통해 최종 확정한다.

## 4. AI 검색 정책

- AI 검색은 본인인증이나 계정 식별 기능이 아니다.
- AI 검색은 포털 검색처럼 사용자가 선택한 키워드를 외부 서비스로 전달하여 검색/질의하는 연동 기능으로 정의한다.
- 외부 서비스 연동 시 문서 원문, 개인정보, 민감정보가 불필요하게 전송되지 않도록 별도 정책을 둔다.
